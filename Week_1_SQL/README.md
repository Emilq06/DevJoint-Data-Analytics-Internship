# devjoint-sql-checkpoints
# DevJoint SQL Internship — Northwind DB Project

Bu repository **DevJoint SQL Internship** proqramı çərçivəsində **Northwind** verilənlər bazası üzərində yerinə yetirilmiş 6 Checkpoint tapşırığının SQL kodlarını və icra nəticələrini ehtiva edir.

---

## 📌 Layihənin Struktur və Məzmunu

* **Checkpoint 1:** DB Browser for SQLite üzərində Northwind bazasının quraşdırılması, `SELECT`, `WHERE`, `ORDER BY` və `LIMIT` ilə əsas sorğular.
* **Checkpoint 2:** `INNER JOIN`, `LEFT JOIN` və `RIGHT JOIN` istifadəsi, Fan-out probleminin və `NULL` qiymətlərin idarə olunması.
* **Checkpoint 3:** `GROUP BY`, `HAVING`, `AVG` və `SUM` ilə aqreqasiya, gəlir və satış analitikası.
* **Checkpoint 4:** Çox addımlı məntiq üçün Subquery və `WITH` (CTE - Common Table Expressions) tətbiqi.
* **Checkpoint 5:** Analitik Window Funksiyaları — `ROW_NUMBER()`, `DENSE_RANK()` və `SUM() OVER` ilə Running Total hesabatları.
* **Checkpoint 6:** Sorğu optimallaşdırılması — Correlated Subquery-nin `JOIN`-a çevrilməsi və İndekslərin (`INDEX`) yaratması.
