🚀 Həftəlik Layihələrin İcmalı
🔹 Həftə 1: SQL Əsaslardan Qabaqcıl (Northwind DB)
Mövzu: SQLite üzərində Northwind bazası ilə 6 mərhələli kompleks analiz.

Əsas Bacarıqlar: Complex JOINs, Aggregations, CTEs, Window Functions (ROW_NUMBER, DENSE_RANK, Running Total) və Query Optimization (Indexing, Subquery to JOIN).

Ətraflı: Week_01_SQL/ qovluğunda tanış ola bilərsiniz.

🔹 Həftə 2: Excel / Google Sheets Analizi
Mövzu: Xam satış/marketing datası üzərində data təmizləmə, lookup funksiyaları, pivot cədvəllər və vizual dashboard qurulması.

Əsas Bacarıqlar: Data Cleaning (TRIM, duplicates), XLOOKUP/VLOOKUP, SUMIFS/COUNTIFS, Conditional Formatting və Interactive Dashboards.

Ətraflı: Week_02_Excel/ qovluğunda tanış ola bilərsiniz.
